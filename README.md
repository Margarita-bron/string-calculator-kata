# String Calculator Kata (PHP + PHPUnit)

## 📖 Overview
This project is a study exercise in **modular unit testing** using **PHPUnit** and the **TDD (Test-Driven Development)** approach.  
The main goal is to implement the classic **String Calculator Kata**.

## 🛠️ Technologies (Stack)
Language: PHP 8.x
Testing Framework: PHPUnit
Approach: Test-Driven Development
Dependency Manager: Composer

## 🚀 Installation & Run

```bash
# Install dependencies
composer install

# Run unit tests
./vendor/bin/phpunit
